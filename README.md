### 🎯 Project Objective
To analyze customer churn behavior in a telecom company and identify the key factors driving churn to help improve customer retention.

### 🔧 Tools & Technologies Used
- Microsoft Excel (Data Cleaning, Formulas, Pivot Tables, EDA)
- Power BI (Data Modeling, DAX, Interactive Visualizations)
- GitHub (Version Control & Project Submission)

### 📈 Key Insights & Findings
From the analysis of 7043 customers:

1.  **Churn Rate:** 26.54% of customers have churned.
2.  **Contract Type:** Customers with **Month-to-Month** contracts have the highest churn rate (~42%).
3.  **Internet Service:** **Fiber Optic** users have significantly higher churn compared to DSL.
4.  **Payment Method:** Customers using **Electronic Check** are more likely to leave.
5.  **Tenure:** New customers (Tenure 0-12 months) churn the most. Longer tenure = higher loyalty.

### 📊 Dashboard Highlights
The Power BI dashboard includes KPIs for Total Customers, Churn Rate, and visual breakdowns by Contract, Internet Service, Payment Method, and Tenure.
